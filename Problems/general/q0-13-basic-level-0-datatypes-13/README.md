## 📝 Problem Statement

Write a program to accept a number as input from the user which denotes the radius of a circle. Calculate the area of the circle and print it.
Use Pi value = 3.14

## 🧪 Examples

### Example 1

**Input:**
```text
15
```

**Expected Output:**
```text
706.50
```

### Example 2

**Input:**
```text
123
```

**Expected Output:**
```text
47505.06
```
